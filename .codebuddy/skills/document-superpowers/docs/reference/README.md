# Reference Materials

Place reference materials in this folder to provide context for your writing projects.

## Supported Formats

| Format | Extensions | How It's Used |
|--------|-----------|---------------|
| Plain Text | `.txt` | Direct text reading and extraction |
| Markdown | `.md` | Structured content reading with section awareness |
| PDF | `.pdf` | Full-text extraction and summarization |
| Images | `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp` | Visual content analysis and description |

## Organization

You can organize materials in any way that makes sense for your project:

```
docs/reference/
├── competitor-analysis.pdf
├── brand-guidelines.md
├── meeting-notes.txt
├── architecture-diagram.png
├── project-name/
│   ├── spec.pdf
│   ├── wireframe.png
│   └── notes.md
└── ...
```

## Usage

When you start a writing project with Document Superpowers, the `reference-material` skill will:

1. **Scan** this folder for available files
2. **Present** a summary of what's available
3. **Let you select** which materials are relevant
4. **Extract** key information from selected files
5. **Feed** extracted context into brainstorming, planning, and execution stages

## Tips

- **Name files descriptively** — `api-design-spec-v2.pdf` is better than `doc1.pdf`
- **Use subfolders** for project-specific materials
- **Keep files focused** — smaller, topic-specific files work better than large dumps
- **Images work best** when they contain diagrams, charts, or UI screenshots
