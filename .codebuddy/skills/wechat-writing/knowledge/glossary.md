## 一、AI核心概念

### 大模型（LLM / Large Language Model）

- **定义**：经过海量文本训练的大规模语言模型，能理解和生成人类语言
- **通俗解释**：一个读过整个互联网的超级学霸，你问什么它都能回答，但偶尔也会"一本正经地胡说八道"
- **代表**：GPT系列、Claude系列、Gemini、Kimi（月之暗面）、DeepSeek
- **验证来源**：OpenAI官方文档、Anthropic官方文档

### Prompt（提示词）

- **定义**：用户输入给AI模型的指令或问题，用于引导模型生成期望的输出
- **通俗解释**：给AI下的"任务说明书"——说得越清楚，AI干得越好
- **职场应用**：写周报的提示词、做PPT大纲的提示词、分析数据的提示词
- **验证来源**：OpenAI Prompt Engineering Guide、Anthropic Prompt Guide

### Prompt Engineering（提示工程）

- **定义**：系统化地设计和优化提示词，以获得更好的AI输出结果的方法论
- **通俗解释**：学会"正确地跟AI说话"的技术——同样一件事，换个说法，AI的表现天差地别
- **验证来源**：OpenAI官方指南、Anthropic官方指南

### RAG（Retrieval-Augmented Generation / 检索增强生成）

- **定义**：在AI生成回答前，先从外部知识库中检索相关信息，再结合检索结果生成更准确的回答
- **通俗解释**：给AI配了一个"随身图书馆"——回答问题前先查资料，不再纯靠记忆瞎编
- **职场应用**：企业知识库问答、文档智能检索
- **验证来源**：Meta AI原始论文（Lewis et al., 2020）、各云厂商RAG产品文档

### AI Agent（智能体）

- **定义**：能够自主规划任务、调用工具、执行多步骤操作的AI系统，不仅能对话，还能"动手干活"
- **通俗解释**：从"只会聊天的AI"进化成"能帮你跑腿办事的AI助理"——你说目标，它自己拆解步骤、调用工具、完成任务
- **职场应用**：自动写代码、自动整理数据、自动发邮件
- **验证来源**：Anthropic MCP文档、OpenAI Agents SDK文档

### MCP（Model Context Protocol / 模型上下文协议）

- **定义**：由Anthropic提出的开放标准协议，让AI模型能够标准化地连接外部工具和数据源
- **通俗解释**：AI世界的"USB接口"——有了这个标准，AI可以像插U盘一样接入各种工具
- **验证来源**：Anthropic MCP官方文档（modelcontextprotocol.io）

### Function Calling（函数调用）

- **定义**：AI模型在对话中识别需要调用外部工具的时机，并生成结构化的调用请求
- **通俗解释**：AI学会了"打电话求助"——遇到自己搞不定的事（查天气、算汇率），它知道该找谁帮忙
- **验证来源**：OpenAI Function Calling文档、Anthropic Tool Use文档

### Fine-tuning（微调）

- **定义**：在预训练大模型的基础上，用特定领域的数据进一步训练，使模型更适应某个专业场景
- **通俗解释**：给通才AI做"专业培训"——本来什么都会一点，培训后在某个领域特别厉害
- **验证来源**：OpenAI Fine-tuning Guide

### Token

- **定义**：AI模型处理文本的基本单位，大致相当于一个词或几个字符
- **通俗解释**：AI读写文字的"计量单位"——1个中文汉字大约消耗1-2个token，token越多，花钱越多
- **验证来源**：OpenAI Tokenizer工具

### Hallucination（幻觉）

- **定义**：AI模型生成的内容看似合理但实际上是错误的或虚构的现象
- **通俗解释**：AI"一本正经地胡说八道"——它说得很自信，但说的可能是假的
- **职场提醒**：重要数据和事实必须人工核实，不能盲信AI输出
- **验证来源**：各大模型厂商安全文档

### Multimodal（多模态）

- **定义**：AI模型能同时理解和处理文字、图片、音频、视频等多种类型的信息
- **通俗解释**：AI不只能"读文字"了，还能"看图片、听声音、看视频"——真正的多面手
- **验证来源**：GPT-4V/GPT-4o、Gemini、Claude 3.5等多模态模型文档

## 三、职场场景术语

| 术语 | 通俗解释 |
|------|---------|
| **周报/日报** | 定期向上级汇报工作进展的文档 |
| **OKR** | 目标与关键结果（Objectives and Key Results），一种目标管理方法 |
| **KPI** | 关键绩效指标（Key Performance Indicator），衡量工作成效的量化指标 |
| **复盘** | 对已完成的工作/项目进行回顾分析，总结经验教训 |
| **对齐** | 确保团队成员对目标、方向、进度达成一致理解 |
| **拉通** | 跨部门/跨团队的信息同步和协作 |
| **颗粒度** | 描述工作拆解的精细程度 |
| **方法论** | 系统化的工作方法和思维框架 |
| **赋能** | 通过培训、工具等方式提升他人/团队的能力 |
| **降本增效** | 降低成本、提升效率，职场高频词 |

## 四、术语使用规范

### 在文章中引用术语时的格式

1. **首次出现**：术语名（通俗解释）
   - 示例："RAG（检索增强生成，简单说就是给AI配了个随身图书馆）"
2. **后续出现**：直接使用术语名，不再重复解释
3. **英文缩写**：首次出现时给出全称
   - 示例："MCP（Model Context Protocol，模型上下文协议）"

### 交叉验证要求

每次在文章中使用术语时，技能需要：
1. 先查询本术语表获取基础定义
2. 联网搜索验证该术语/工具是否仍然准确（名称、版本、状态）
3. 如发现不一致，以最新可信信息为准，并更新术语表
