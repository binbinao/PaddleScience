# 标题公式库

> **用途**：标题生成阶段，根据选题特征匹配最佳公式，生成3-5个标题备选。

---

## 六大标题公式

### 公式1：数字+痛点+解决方案

**模板**：`X个方法/技巧 + 解决Y痛点 + 获得Z结果`

**适用场景**：工具推荐、效率技巧、方法论总结

**AI+职场案例**：
- "5个AI工具，让你的PPT制作效率提升10倍"
- "3个Prompt技巧，让ChatGPT写出老板满意的周报"
- "7个AI快捷操作，每天帮你省出2小时"

**要点**：
- 数字要具体（奇数比偶数更吸引眼球）
- 痛点要精准（对应目标读者的真实困扰）
- 结果要量化（提升X倍、省X小时、涨X%）

---

### 公式2：前后对比+具体数字

**模板**：`从X到Y + 时间/方法`

**适用场景**：逆袭故事、效率提升、工具实测

**AI+职场案例**：
- "从日报写2小时到15分钟，我只用了这1个AI工具"
- "从月薪8K到月薪3W，我做对了这件事：学会用AI"
- "从PPT小白到汇报高手，Gamma帮我实现了"

**要点**：
- 前后反差要大（制造视觉冲击）
- 数字要具体可信（太夸张会被认为标题党）
- 方法要简单（暗示读者也能做到）

---

### 公式3：否定句式+逆向思维

**模板**：`千万别/别再 + 常见做法 + 正确方法`

**适用场景**：认知纠偏、避坑指南、反常识观点

**AI+职场案例**：
- "别再用ChatGPT写周报了！这个方法才是正解"
- "千万别直接让AI帮你做PPT，先做这一步"
- "停止无脑学AI！90%的人方向就错了"

**要点**：
- 否定的必须是读者正在做的事（才有冲击力）
- 紧跟正确方案（否则只有恐惧没有价值）
- 适度使用，频率太高会产生疲劳

---

### 公式4：身份认同+痛点

**模板**：`特定人群标签 + 痛点 + 情感词`

**适用场景**：精准圈定目标读者、情感共鸣

**AI+职场案例**：
- "35岁职场人必看：AI不会淘汰你，不会用AI的人会"
- "运营人醒醒！你的竞争对手已经在用AI批量出稿了"
- "程序员转型指南：AI时代，你的代码能力只值一半了"

**要点**：
- 人群标签要精准（35岁、运营人、程序员）
- 痛点要扎心但不焦虑贩卖（给出路感）
- 情感词增加画面感和代入感

---

### 公式5：提问引导+答案预告

**模板**：`为什么 + 现象 + ？（答案出乎意料）`

**适用场景**：好奇心驱动、认知升级、深度解读

**AI+职场案例**：
- "为什么同事用AI效率是你的5倍？差距在这3点"
- "为什么你用了10个AI工具，工作量反而更大了？"
- "AI时代最值钱的能力是什么？不是你以为的那个"

**要点**：
- 问题必须是读者也在困惑的（才有点击欲望）
- 暗示答案出乎意料（蔡格尼克效应：未完成问题驱动点击）
- 问题本身就要有信息量

---

### 公式6：独家揭秘+稀缺性

**模板**：`行业秘密/内部方法 + 数据 + 很少人知道`

**适用场景**：深度干货、独家方法论、行业内幕

**AI+职场案例**：
- "大厂都在用的AI办公流程，今天全部公开"
- "我花2万学的AI课，核心就这5个方法"
- "面试官不会告诉你的：AI岗位真正看中的3项能力"

**要点**：
- 稀缺性要真实可信（"首次公开""内部方法"）
- 必须兑现承诺（内容要配得上标题的期待值）
- 慎用"独家""内幕"等词，避免标题党

## 标题通用规范

| 规范 | 说明 |
|------|------|
| **字数** | 13-20字为最佳 |
| **括号补充** | 可提升点击率38%，如"（附完整教程）" |
| **禁用极限词** | 最、第一、史上最全、永久（违规+限流） |
| **极限词替换** | "史上最全"→"保姆级"；"最好"→"强推"；"第一"→"头部" |
| **标题党红线** | 标题与内容必须相关，否则算法降权+用户举报 |
| **数字效应** | 含数字的标题点击率平均高出36% |
| **情绪词** | 适度使用："居然""真相""醒醒""扎心了" |

## 标题生成流程

1. 分析选题特征（工具类/故事类/观点类/教程类）
2. 匹配2-3个最适合的公式
3. 每个公式生成1-2个标题变体
4. 标注每个标题所用的公式编号
5. 推荐首选标题并说明理由
