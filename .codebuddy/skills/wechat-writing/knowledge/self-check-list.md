# 自检清单

> **用途**：全文生成后，逐项检查文章质量。所有项必须通过才能进入排版阶段。

---

## 核心检查项（8项必检）

### 1. 金句数量 ≥ 3

- [ ] 开头附近有1个定调金句
- [ ] 中部有1个核心观点金句
- [ ] 结尾有1个升华金句
- [ ] 金句简短有力（≤15字最佳）
- [ ] 金句可独立传播（脱离上下文也有意义）
- [ ] 金句有观点、有态度（非空泛鸡汤）

### 2. 段落长度 ≤ 4行

- [ ] 每段不超过4行（手机端显示标准）
- [ ] 每段2-4句话
- [ ] 无超过100字的单段
- [ ] 段间有适当留白

### 3. 术语已解释

- [ ] 所有专业术语首次出现时附有通俗解释
- [ ] 英文缩写首次出现时给出全称
- [ ] 术语解释用括号或破折号内嵌（不打断阅读节奏）
- [ ] 术语经过交叉验证（与术语表一致+联网确认最新信息）

### 4. 有互动引导

- [ ] 结尾有明确的互动引导（提问/投票/评论邀请）
- [ ] 互动问题与文章主题相关
- [ ] 互动门槛低（读者容易回答）

### 5. ABBB标记到位

- [ ] 每节核心结论有加粗标记
- [ ] 关键数据/概念有高亮标记
- [ ] 只看加粗/高亮内容即可理解文章主旨
- [ ] 加粗不超过每段1-2处（避免过度加粗）

### 6. 情绪弧线完整

- [ ] 开头制造了焦虑/好奇/共鸣
- [ ] 中部提供了干货/安全感/方法
- [ ] 结尾给出了力量/行动感/希望
- [ ] 全文情绪不单调（有起伏变化）

### 7. 句式多样性

- [ ] 无连续3个相同长度的句子
- [ ] 长短句交替使用
- [ ] 无连续3段以相同方式开头
- [ ] 有设问句、感叹句等变化（不全是陈述句）

### 8. 去AI腔

- [ ] 无"值得注意的是""综上所述""不可否认"等填充短语
- [ ] 无"在当今……的大背景下"等空泛开场
- [ ] 无"此外""然而"过度使用（全文≤2次）
- [ ] 无三段式堆砌（"无论是……还是……亦或是……"）
- [ ] 无否定式排比（"这不仅仅是……而是……"）
- [ ] 无模糊归因（"专家认为""研究表明"需给出具体来源）
- [ ] 无过度加粗（非每段都有粗体）
- [ ] 读起来像真人写的，不像AI生成的

---

## 附加检查项（建议检查）

### 标题质量

- [ ] 标题13-20字
- [ ] 含数字或具体信息
- [ ] 与内容高度相关（非标题党）
- [ ] 无违规极限词（最、第一、史上最全）

### 结构完整性

- [ ] 有明确的Hook开头
- [ ] 有冲突/问题的揭示
- [ ] 有核心论述（分小节+小标题）
- [ ] 有行动指南（可落地的步骤）
- [ ] 有收尾升华

### 信息密度

- [ ] 无大段废话或注水
- [ ] 每个段落都有实质信息
- [ ] 案例具体、数据真实
- [ ] 全文字数在1500-3000字范围内

### 视觉元素

- [ ] 每500-800字至少有1处视觉元素占位（配图/表格/引用框）
- [ ] 有小标题分节（读者可跳读）
- [ ] 关键内容有视觉突出标记

## 自检评分表

| 维度 | 满分 | 评分标准 |
|------|------|---------|
| **信息价值** | 10 | 读完有收获感？10=干货满满；1=全是废话 |
| **可读性** | 10 | 读起来流畅吗？10=一口气读完；1=频繁卡顿 |
| **人格化** | 10 | 像真人写的吗？10=个性鲜明；1=百科词条 |
| **行动力** | 10 | 读完想行动吗？10=立刻想试；1=无感 |
| **传播性** | 10 | 想转发吗？10=必须分享；1=看完就忘 |
| **总分** | **50** | ≥40分可发布；35-39分需优化；<35分需重写 |
