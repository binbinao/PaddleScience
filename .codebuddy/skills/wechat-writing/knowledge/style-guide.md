# 行文风格规范

> **用途**：全文生成和自检阶段的核心参照标准。
> 
> **风格定位**：融合刘润（结构化）、半佛仙人（人格化）、AI信息派（高密度）、职场叙事派（共鸣）四家之长。

---

## 一、语言层面

| 维度 | 规范 | 正例 | 反例 |
|------|------|------|------|
| **人称** | 以"你"为主，营造一对一对话感 | "你有没有遇到过这种情况？" | "大家可能都遇到过……" |
| **句长** | 每句不超过25字，短句为主 | "AI不会淘汰你。不会用AI的人才会。" | "在当今人工智能飞速发展的时代背景下，那些不能够熟练运用AI工具的人可能会面临被淘汰的风险。" |
| **段落** | 每段2-4句，手机端不超过4行 | 短段落，留白充足 | 一整屏密密麻麻的文字 |
| **术语** | 专业术语首次出现必须当场解释 | "RAG（简单说就是给AI配了个随身图书馆）" | 直接用"RAG"不解释 |
| **口语化** | 书面语为底，适度口语化 | "所以""说白了""换句话说" | "因此""综上所述""鉴于此" |
| **比喻** | 用生活化类比解释技术概念 | "MCP就是AI世界的USB接口" | "MCP是一种标准化的模型上下文协议" |
| **连接词** | 少用"此外""然而""总而言之" | 用句意自然衔接 | 每段开头一个"此外" |

## 二、节奏层面

### ABBB法则

核心观点需要视觉突出，确保读者快速滑动时也能捕捉到关键信息：

- **A（加粗）**：每节的核心结论加粗
- **B（标蓝/高亮）**：关键数据、关键概念用特殊颜色标记
- 确保只看加粗/标蓝内容就能理解文章主旨

### 信息-故事交替

```
干货段落（200-300字）
    ↓
案例/故事/截图（100-200字）
    ↓
干货段落（200-300字）
    ↓
案例/故事/截图（100-200字）
```

- 每300字左右穿插一个案例、故事、截图或数据
- 防止阅读疲劳，维持注意力曲线

### 转折钩子

每节结尾设置悬念或过渡，引导继续阅读：

- "但这还不是最厉害的。"
- "然而，真正的问题在下一步。"
- "接下来这个方法，才是今天的重点。"

### 金句节点

全文至少3个可截图传播的金句，分布在：

1. **开头附近**（1个）：定调金句
2. **中部高潮**（1个）：核心观点金句
3. **结尾收束**（1个）：升华金句

金句特征：
- 简短有力（15字以内最佳）
- 有观点、有态度
- 可以独立传播（脱离上下文也有意义）
- **拒绝鸡汤式金句**：要有具体洞察，不要空泛励志

## 三、情感层面

### 基调

**专业但不冷冰冰，有温度但不鸡汤。**

| 要 | 不要 |
|----|------|
| 像一个有经验的朋友在分享 | 像一个居高临下的导师在教训 |
| 承认不确定性和复杂性 | 把一切说得斩钉截铁 |
| 适度自嘲，暴露自己也踩过坑 | 全程完美人设，毫无破绽 |
| 留空间让读者自己思考 | 强行灌输结论 |

### 情绪弧线模板

```
开头：制造焦虑/好奇
  ↓  "你是不是也有这种感觉——AI工具越来越多，但效率反而没提升？"
  
中部：给干货/安全感
  ↓  "别慌，问题不在AI，在于你的使用方式。这3个方法亲测有效。"
  
结尾：给力量/行动感
      "今天就试试第2个方法，明天上班你会感谢自己。"
```

### 姿态校准

| 场景 | 姿态 |
|------|------|
| 讲方法论 | 平等分享者："我发现一个好用的方法，分享给你" |
| 讲热点 | 理性观察者："我们来看看这件事到底意味着什么" |
| 讲故事 | 坦诚叙述者："说实话，我一开始也不信" |
| 讲工具 | 实测体验者："我用了一周，说说真实感受" |

## 四、结构层面

### 通用骨架（SCQA+五商派融合）

```
┌─────────────────────────────────────────────┐
│ ① Hook开头（100-150字）                       │
│    场景切入 / 痛点描述 / 热点事件 / 金句破题    │
├─────────────────────────────────────────────┤
│ ② 冲突/问题（200-300字）                      │
│    揭示矛盾 / 打破认知 / "你以为…其实…"        │
├─────────────────────────────────────────────┤
│ ③ 核心论述（800-1500字，分2-4个小节）          │
│    每节：小标题 → 论点 → 案例/数据 → 小结      │
│    技巧：故事化表达、截图实操、对比展示          │
├─────────────────────────────────────────────┤
│ ④ 行动指南（200-400字）                       │
│    可落地的步骤 / 工具推荐 / 操作流程            │
├─────────────────────────────────────────────┤
│ ⑤ 收尾升华（100-200字）                       │
│    金句总结 / 情感共鸣 / 互动引导 / 下期预告     │
└─────────────────────────────────────────────┘
```

### 三种子风格的结构微调

#### 理性干货型

- 开头简短直入主题（50-100字）
- 核心论述占比更大（60-70%）
- 多用截图、步骤编号、对比表格
- 行动指南详细具体

#### 故事驱动型

- 开头用场景描写/对话（150-200字）
- 穿插个人经历和心路历程
- 核心论述中故事和方法论交替
- 收尾回扣开头故事，形成闭环

#### 观点输出型

- 开头直接亮观点或抛问题
- 用SCQA框架层层推进
- 核心论述以论点→论据→反驳→结论展开
- 收尾强化观点，适度引发争议

## 五、开头技巧（Top 5）

| # | 技巧 | 模板 | 示例 |
|---|------|------|------|
| 1 | **痛点切入** | 你是不是也…… | "你是不是也有这种感觉——AI工具越来越多，但工作效率反而没提升？" |
| 2 | **场景描写** | 时间+地点+动作 | "上周五晚上9点，我还在公司改第7版PPT。直到同事发来一个链接……" |
| 3 | **数据冲击** | 一项调查/数据显示…… | "一项调查显示：会用AI的职场人，平均每天省出2.3小时。" |
| 4 | **热点嫁接** | XX刚发布/刚发生…… | "GPT-5发布3天后，我老板让全组学会用它写周报。" |
| 5 | **逆向认知** | 我劝你别…… / 你以为…其实…… | "我劝你，别急着学AI。先搞清楚一件事。" |

## 六、结尾技巧（Top 5）

| # | 技巧 | 模板 | 示例 |
|---|------|------|------|
| 1 | **金句升华** | 一句话总结全文 | "工具会过时，但学会和AI协作的能力，永远不会过时。" |
| 2 | **行动号召** | 今天就…… | "今天就试试第2个方法，明天上班你会感谢自己。" |
| 3 | **互动引导** | 你平时……评论区聊聊 | "你平时用什么AI工具提升工作效率？评论区聊聊。" |
| 4 | **观点重申+升维** | 重申核心+更高维度 | "AI不是来抢你饭碗的。它是来帮你换一个更大的碗。" |
| 5 | **下期预告** | 下一篇我们聊…… | "下一篇，我会详细拆解Cursor的10个隐藏技巧，记得关注。" |

## 七、反面清单（绝对避免）

| 问题 | 说明 |
|------|------|
| ❌ AI百科腔 | "在当今数字化转型的大背景下……" |
| ❌ 填充短语 | "值得注意的是""需要指出的是""不可否认的是" |
| ❌ 三段式堆砌 | "无论是……还是……亦或是……" |
| ❌ 空泛鸡汤 | "只要努力，一切皆有可能" |
| ❌ 过度加粗 | 每段都有3-4处加粗（应该每段最多1-2处） |
| ❌ 破折号滥用 | 一段中出现3个以上破折号 |
| ❌ 否定式排比 | "这不仅仅是……而是……" |
| ❌ 模糊归因 | "专家认为""有人说""研究表明"（不给出具体来源） |
