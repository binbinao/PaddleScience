# 微信公众号写作技能（WeChat Writing）

## 概述

为"AI+职场"赛道提供从选题到排版的全流程公众号文章写作辅助。采用混合模式——先以教练身份引导用户完成选题、标题、大纲，确认后再生成全文并排版。

## 触发条件

当用户表达以下意图时激活本技能：
- "写一篇公众号文章"
- "帮我写篇推文"
- "公众号选题/标题/大纲"
- "写一篇关于……的公众号"
- 任何涉及公众号内容创作的请求

## 核心定位

| 维度 | 规范 |
|------|------|
| **赛道** | AI + 职场效率 |
| **风格** | 融合性通用风格（理性结构+适度幽默+人格化温度） |
| **模式** | 混合模式（教练引导→确认→生成全文→排版） |
| **默认字数** | 1500-3000字（标准模式），超出需与用户协商 |
| **输出目录** | `docs/wechat/` |

## 风格DNA

本技能融合四家头部公众号之长：

| 来源 | 融合元素 |
|------|---------|
| **刘润**（理性结构派） | SCQA框架、逻辑势能、"你"的对话感、金句收尾 |
| **半佛仙人**（犀利人格派） | 专业下沉通俗化、适度幽默自嘲、强人格化 |
| **AI信息派**（歸藏/宝玉） | 高信息密度、截图+步骤式实操、结论前置 |
| **职场叙事派**（粥左罗/Spenser） | 真实故事穿插、情绪弧线、行动号召 |

## 六步工作流

```
用户输入主题/素材
      ↓
① 选题分析 + 子风格推荐
   （热度评估、四因素打分、赛道匹配、智能推荐子风格）
      ↓
② 标题生成
   （提供3-5个标题备选，标注所用公式）
      ↓
③ 大纲规划
   （SCQA结构、各节要点、预估字数）
      ↓
 [用户确认/修改]  ← 硬门禁：必须获得用户确认才能继续
      ↓
④ 全文生成
   （按风格规范逐节撰写，术语自动匹配术语表并附通俗解释）
      ↓
⑤ 自检优化
   （金句数量、段落长度、ABBB标记、情绪弧线、术语交叉验证）
      ↓
⑥ 排版输出
   （加粗/标蓝标记、引用框、配图占位、金句卡片、小标题层级）
      ↓
 [用户终审]
```

<HARD-GATE>
在用户确认大纲之前，不得生成全文。步骤①②③为教练引导阶段，必须逐步完成并获得用户认可。
</HARD-GATE>

## 三种子风格

技能根据主题智能推荐子风格，用户可覆盖：

| 子风格 | 适用场景 | 特征侧重 |
|--------|---------|---------|
| **理性干货型** | AI工具测评、技术解读 | 高信息密度、结论前置、截图步骤、少情绪 |
| **故事驱动型** | 职场逆袭、个人经历 | 场景描写、情感弧线、对话还原、金句多 |
| **观点输出型** | 行业趋势、热点评论 | SCQA框架、犀利论点、数据佐证、适度幽默 |

### 子风格推荐规则

```
IF 主题含工具名/产品名/教程/实测 → 推荐"理性干货型"
IF 主题含个人经历/故事/逆袭/转型 → 推荐"故事驱动型"
IF 主题含趋势/热点/观点/评论/分析 → 推荐"观点输出型"
IF 无法判断 → 默认"观点输出型"，提示用户确认
```

### 术语交叉验证规则

1. **静态验证**：术语表内置时，每个概念通过多个可信来源验证准确性
2. **动态验证**：每次生成文章时，对涉及的术语实时联网搜索验证最新信息
3. **更新机制**：如发现术语表中的信息已过时（工具更名、下线、概念演进），立即更新术语表

## 注意事项

1. **字数限制**：默认1500-3000字，如选题需要超出，必须与用户协商确认
2. **术语准确性**：所有AI概念和工具名称必须交叉验证，不得想当然
3. **人格化优先**：即使是干货型文章，也必须有"人味"，拒绝百科式冷冰冰的叙述
4. **拒绝AI腔**：生成的文章需符合 humanizer-zh 标准，避免AI写作痕迹
5. **配图意识**：排版阶段标注配图占位，建议每500-800字至少一处视觉元素
6. **立场先于结构**：在选题阶段必须明确"作者对这件事的立场是什么"。没有立场的文章，再怎么套方法论都是空的。立场不是"中立介绍"，是"我认为……因为……"
7. **砍掉90%，写透10%**：公众号文章不是信息压缩，是一个角度的深挖。宁可只讲一个最有冲击力的细节讲透，也不要试图覆盖原始素材的全部内容
8. **读者在哪看到这件事**：选题分析时必须搞清楚目标读者是从什么渠道接触到这个话题的（朋友圈广告？培训推送？同事聊天？），用那个场景开头，而不是用行业背景开头
9. **谁在赚钱**：对于热点话题，必须分析商业链条——谁在推、谁在卖、谁在割。这是揭黑者视角的核心武器
10. **建议必须可执行**：给读者的行动建议必须具体到"下载哪个App""点哪个按钮"的程度。"关注能力不关注工具"这种话等于没说
11. **标题必须匹配读者焦虑**：标题不是概括文章内容，是命中读者正在经历的情绪。从读者的FOMO焦虑出发，而非从文章的信息点出发
