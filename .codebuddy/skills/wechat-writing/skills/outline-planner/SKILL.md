# 大纲规划

## 概述

根据已确认的选题和标题，生成详细的文章大纲。这是教练引导阶段的最后一步，必须获得用户确认后才能进入全文生成。

<HARD-GATE>
大纲必须获得用户明确确认后，才能进入全文生成阶段。如果用户有修改意见，必须先修改大纲再确认。
</HARD-GATE>

## 前置条件

- 选题分析已完成，子风格已确认
- 标题已选定

## 任务清单

1. **加载风格规范**：读取 `knowledge/style-guide.md` 中的结构模板
2. **构建骨架**：按SCQA+五商派融合结构搭建大纲
3. **细化各节**：每节标注要点、预估字数、需要的素材类型
4. **分配字数**：确保总字数在1500-3000字范围内
5. **标注术语**：预标记需要解释的专业术语
6. **输出大纲**：保存到 `docs/wechat/YYYY-MM-DD-<topic>-outline.md`
7. **等待确认**：用户确认后进入全文生成

## 大纲结构模板

### 理性干货型

```
① Hook开头（80-120字）
   - 痛点切入 / 数据冲击
   - 预告文章价值

② 问题揭示（200-300字）
   - 为什么这个问题重要
   - 常见误区是什么

③ 核心干货（800-1200字，分3-4节）
   - 3.1 [方法/工具1]：论点+操作步骤+截图占位
   - 3.2 [方法/工具2]：论点+操作步骤+截图占位
   - 3.3 [方法/工具3]：论点+对比数据
   - 3.4 [进阶技巧]（可选）

④ 行动指南（200-300字）
   - 推荐的起步路径
   - 具体的第一步操作

⑤ 收尾（80-120字）
   - 金句总结
   - 互动引导
```

### 故事驱动型

```
① 场景开头（120-180字）
   - 具体的时间/地点/事件
   - 制造悬念

② 转折（200-300字）
   - 困境/挑战
   - 转机出现

③ 核心经历+方法论（800-1200字，分3-4节）
   - 3.1 [经历1]：故事+感悟+方法
   - 3.2 [经历2]：故事+感悟+方法
   - 3.3 [总结提炼]：从个人经历抽象出通用方法论

④ 行动建议（200-300字）
   - 读者可以怎么做
   - 具体步骤

⑤ 收尾（100-150字）
   - 回扣开头场景（闭环）
   - 情感升华+金句
```

### 观点输出型

```
① 破题（100-150字）
   - 热点事件/现象引入
   - 直接亮出核心观点

② 背景+冲突（200-300字）
   - 事件/现象的来龙去脉
   - 主流看法 vs 你的不同看法

③ 核心论证（800-1200字，分2-3节）
   - 3.1 [论点1]：论据+数据+反驳常见误解
   - 3.2 [论点2]：论据+案例
   - 3.3 [延伸思考]：更深一层的洞察

④ 对读者的影响（200-300字）
   - 这意味着什么
   - 应该如何应对

⑤ 收尾（100-150字）
   - 强化观点（金句）
   - 引发讨论的开放性问题
```
