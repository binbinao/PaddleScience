# 排版输出

## 概述

将自检通过的文章转换为带有完整公众号排版标记的终稿，方便用户直接复制到秀米/壹伴/微信编辑器使用。

## 前置条件

- 自检优化已完成且通过

## 任务清单

1. **读取初稿**：加载自检优化后的文章
2. **应用格式标记**：按排版规范添加所有格式标记
3. **配图占位**：确保每500-800字有视觉元素占位
4. **金句卡片**：将金句标记为可制作卡片的样式
5. **小标题层级**：规范化小标题样式
6. **最终检查**：确认排版完整性
7. **输出终稿**：保存到 `docs/wechat/YYYY-MM-DD-<topic>-final.md`

## 排版规范

### 文本格式

| 元素 | Markdown标记 | 排版效果 | 使用场景 |
|------|-------------|---------|---------|
| 核心结论 | `**加粗**` | 加粗 | 每节1-2处核心论点 |
| 关键数据 | `==高亮==` | 标蓝/高亮 | 重要数据、关键概念 |
| 金句 | `> 引用` | 引用框 | 全文3+个金句 |
| 配图占位 | `<!-- 配图：描述 -->` | 图片位置 | 每500-800字1处 |
| 分隔线 | `---` | 视觉分隔 | 大节之间 |

### 小标题层级

```
# 文章标题（不显示在正文中，用于标识）

## 大节标题（对应大纲的①②③④⑤）

### 小节标题（对应3.1、3.2、3.3）
```

### 配图占位标记规范

```html
<!-- 配图：[图片类型] - [具体描述] -->
```

图片类型：
- **截图**：工具界面、操作步骤
- **对比图**：前后对比、效果对比
- **流程图**：操作流程、思维导图
- **数据图**：图表、统计数据可视化
- **封面图**：文章题图

示例：
```html
<!-- 配图：截图 - Cursor编辑器的AI补全功能界面 -->
<!-- 配图：对比图 - 使用AI前后的周报撰写时间对比 -->
<!-- 配图：流程图 - AI辅助办公的3步工作流 -->
```

### 金句卡片标记

金句使用引用框格式，并添加卡片标记：

```markdown
> 💡 **工具会过时，但学会和AI协作的能力，永远不会过时。**
<!-- 金句卡片：可制作为分享图 -->
```

### 互动区域标记

文章结尾的互动区域：

```markdown
---

💬 **今日互动**

你平时用什么AI工具提升工作效率？评论区聊聊。

👇 点击「在看」，让更多人看到这篇文章。
```

### 文末标准模块

```markdown
---

📌 **关于作者**
[作者简介占位]

🔗 **往期推荐**
- [相关文章1占位]
- [相关文章2占位]

⭐ **觉得有用？** 点赞 + 在看 + 转发，三连支持一下！
```

## 视觉密度检查

| 检查项 | 标准 |
|--------|------|
| 配图占位 | 每500-800字至少1处 |
| 小标题 | 每300-500字至少1个 |
| 引用框 | 全文至少3处（金句） |
| 加粗 | 每节1-2处 |
| 分隔线 | 大节之间 |

## 输出格式

终稿为Markdown文件，包含所有排版标记。文件头部附排版说明：

```markdown
---
title: [文章标题]
date: YYYY-MM-DD
style: [理性干货型/故事驱动型/观点输出型]
word_count: [实际字数]
---

<!-- 
排版说明：
- **加粗** = 核心结论
- ==高亮== = 关键数据（排版时改为标蓝）
- > 引用 = 金句框
- <!-- 配图：描述 --> = 图片占位
- 💡 = 金句卡片标记
-->

[正文内容]
```

## 完成

输出终稿后，通知用户：
1. 终稿文件位置
2. 需要替换的配图占位数量
3. 建议的排版编辑器（秀米/壹伴/135编辑器）
4. 提醒检查配图和最终排版效果
