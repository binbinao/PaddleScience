# 标题生成

## 概述

基于选题分析的结果和6大标题公式，生成3-5个高质量标题备选。

## 前置条件

- 选题分析（topic-analysis）已完成
- 用户已确认选题方向和子风格

## 任务清单

1. **加载标题公式库**：读取 `knowledge/title-formulas.md`
2. **匹配公式**：根据选题特征选择2-3个最适合的公式
3. **生成标题**：每个公式生成1-2个变体，共3-5个标题
4. **标注公式**：每个标题标注所用的公式编号
5. **推荐首选**：推荐1个最佳标题并说明理由
6. **用户选择**：等待用户选择或修改

## 公式匹配规则

| 选题类型 | 优先公式 |
|---------|---------|
| 工具推荐/效率技巧 | 公式1（数字+痛点+方案）、公式2（前后对比） |
| 逆袭故事/经历分享 | 公式2（前后对比）、公式4（身份认同） |
| 认知纠偏/避坑指南 | 公式3（否定句式）、公式5（提问引导） |
| 深度解读/行业分析 | 公式5（提问引导）、公式6（独家揭秘） |
| 热点评论/趋势观察 | 公式4（身份认同）、公式5（提问引导） |

## 输出格式

```
标题备选：

1. 「5个AI工具，让你的PPT制作效率提升10倍」
   → 公式1：数字+痛点+方案

2. 「从日报写2小时到15分钟，我只用了这1个AI工具」
   → 公式2：前后对比+数字

3. 「别再用ChatGPT写周报了！这个方法才是正解」
   → 公式3：否定句式+逆向

4. 「为什么同事用AI效率是你的5倍？差距在这3点」
   → 公式5：提问引导+答案预告

★ 推荐标题：#2
理由：前后对比制造强反差，数字具体可信，暗示方法简单可复制。
```

## 质量检查

每个标题必须满足：
- [ ] 13-20字
- [ ] 无违规极限词
- [ ] 与选题内容一致
- [ ] 有明确的信息增量（看标题就知道文章讲什么）

## 下一步

用户选择标题后，自动进入大纲规划（outline-planner）。
