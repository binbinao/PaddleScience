# 选题分析 + 子风格推荐

## 概述

这是公众号写作的第一步。收到用户的主题/素材后，进行系统化的选题分析，并智能推荐最适合的子风格。

## 任务清单

1. **理解用户输入**：提取主题关键词、目标读者、写作目的
2. **四因素评分**：对选题进行热点/干货/利益/情绪四维度打分
3. **赛道匹配**：评估选题与"AI+职场"赛道的匹配度
4. **子风格推荐**：根据选题特征推荐最佳子风格
5. **输出选题分析报告**：保存到 `docs/wechat/YYYY-MM-DD-<topic>-analysis.md`
6. **自动进入下一步**：调用 title-generator 技能

## 四因素评分模型

对每个选题从1-10分评估：

| 因素 | 评估标准 | 权重 |
|------|---------|------|
| **热点** | 选题是否与近期热门事件/话题相关？时效性如何？ | 25% |
| **干货** | 是否包含新知识、新方法、可落地的技巧？ | 30% |
| **利益** | 是否涉及赚钱、省时、升职、避险等实际利益？ | 25% |
| **情绪** | 是否能引发共鸣、焦虑、好奇、愤怒等情绪？ | 20% |

**综合评分** = 热点×0.25 + 干货×0.30 + 利益×0.25 + 情绪×0.20

**建议阈值**：
- ≥ 7.0：优质选题，强烈建议
- 5.0-6.9：中等选题，可通过标题和切入角度提升
- < 5.0：弱选题，建议换题或调整角度

## 子风格推荐规则

```
IF 主题含工具名/产品名/教程/实测/评测/对比 → 推荐"理性干货型"
IF 主题含个人经历/故事/逆袭/转型/失败/踩坑 → 推荐"故事驱动型"
IF 主题含趋势/热点/观点/评论/分析/预测    → 推荐"观点输出型"
IF 无法判断                              → 默认"观点输出型"，提示用户确认
```

推荐后必须告知用户：
- 推荐的子风格及理由
- 其他两种子风格的简要说明
- 用户可以覆盖推荐

## 输出格式

```markdown
# 选题分析报告

## 主题
[用户输入的主题]

## 四因素评分
| 因素 | 得分 | 说明 |
|------|------|------|
| 热点 | X/10 | [理由] |
| 干货 | X/10 | [理由] |
| 利益 | X/10 | [理由] |
| 情绪 | X/10 | [理由] |
| **综合** | **X.X/10** | |

## 赛道匹配度
[与"AI+职场"赛道的匹配分析]

## 推荐子风格
**[理性干货型/故事驱动型/观点输出型]**
理由：[推荐理由]

## 建议切入角度
1. [角度1]
2. [角度2]
3. [角度3]
```

## 与用户交互

完成分析后，向用户展示：
1. 四因素评分表
2. 推荐的子风格（可覆盖）
3. 3个建议切入角度

等待用户确认或调整后，进入标题生成阶段。
