# 自检优化

## 概述

对全文初稿进行系统化的质量检查，按8项核心检查清单逐项审查，发现问题后自动修复。

## 前置条件

- 全文初稿已完成

## 任务清单

1. **加载自检清单**：读取 `knowledge/self-check-list.md`
2. **逐项检查**：8项核心检查 + 附加检查
3. **术语交叉验证**：联网验证文中所有术语的准确性
4. **标记问题**：记录所有不通过的检查项
5. **自动修复**：修复可以自动修复的问题
6. **人工标注**：标注需要用户判断的问题
7. **评分**：按5维度评分表打分
8. **输出自检报告**：保存到 `docs/wechat/YYYY-MM-DD-<topic>-check.md`
9. **判断是否通过**：
   - ≥ 40分：通过，进入排版
   - 35-39分：提示用户可选择优化或直接排版
   - < 35分：必须修改后重新自检

## 8项核心检查

### Pass 1：金句检查
- 全文金句 ≥ 3个
- 分布合理（开头/中部/结尾各至少1个）
- 金句简短有力、可独立传播
- 非空泛鸡汤

### Pass 2：段落与句式
- 段落 ≤ 4行
- 句长 ≤ 25字
- 无连续3个同长句
- 长短句交替

### Pass 3：术语准确性
- 所有术语首次出现已附解释
- 英文缩写首次出现已给全称
- 联网验证术语/工具的最新状态
- 发现不一致则修正文章并更新术语表

### Pass 4：互动引导
- 结尾有互动引导
- 问题与主题相关
- 门槛低、易参与

### Pass 5：ABBB标记
- 核心结论已加粗
- 关键数据已高亮
- 只看加粗/高亮可理解主旨
- 加粗不超过每段1-2处

### Pass 6：情绪弧线
- 开头有焦虑/好奇/共鸣
- 中部有干货/安全感
- 结尾有力量/行动感
- 情绪有起伏

### Pass 7：句式多样性
- 无连续相同开头
- 有设问句/感叹句变化
- 避免公式化表达

### Pass 8：去AI腔
- 无填充短语
- 无空泛开场
- 无过度连接词
- 无三段式堆砌
- 无否定式排比
- 无模糊归因
- 读起来像真人
