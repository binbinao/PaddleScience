# WeChat Writing Skill（微信公众号写作技能）

面向"AI+职场"赛道的全流程公众号文章写作辅助技能。

## 快速开始

1. 说："帮我写一篇公众号，主题是[你的主题]"
2. 跟随教练引导完成选题→标题→大纲
3. 确认大纲后，技能自动生成全文→自检→排版
4. 在 `docs/wechat/` 中查看终稿

## 核心特性

- **AI+职场赛道专属**：内置行业术语表、选题方向、标题案例
- **融合四家之长**：刘润的结构化 + 半佛仙人的人格化 + AI信息派的高密度 + 职场叙事派的共鸣
- **混合模式**：前3步教练引导（选题→标题→大纲），确认后自动生成全文
- **智能子风格**：根据主题自动推荐理性干货型/故事驱动型/观点输出型
- **术语交叉验证**：内置术语表 + 实时联网验证，确保概念准确
- **内置排版**：输出带完整格式标记的终稿，方便复制到公众号编辑器

## 六步工作流

```
① 选题分析+子风格推荐 → ② 标题生成 → ③ 大纲规划
                                           ↓
                                     [用户确认]
                                           ↓
④ 全文生成 → ⑤ 自检优化 → ⑥ 排版输出
                                ↓
                          [用户终审]
```

## 输出文件

每篇文章产出以下文件，存放在 `docs/wechat/`：

| 文件 | 内容 |
|------|------|
| `*-analysis.md` | 选题分析报告（四因素评分+子风格推荐） |
| `*-outline.md` | 标题+大纲（用户确认版） |
| `*-draft.md` | 全文初稿 |
| `*-check.md` | 自检报告（评分+问题修复记录） |
| `*-final.md` | 排版终稿（可直接复制到编辑器） |

## 设计决策记录

| 决策项 | 结论 |
|--------|------|
| 技能架构 | 独立顶层技能（非document-superpowers插件） |
| 术语表 | 内置+交叉验证+动态联网更新 |
| 子风格 | 智能推荐+用户可覆盖（3种子风格） |
| 文章长度 | 标准模式1500-3000字，超出需协商 |
| 排版 | 作为内置阶段（第6步） |
| 输出目录 | `docs/wechat/`（独立于其他写作项目） |
