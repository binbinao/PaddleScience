# 3米工字梁屈曲分析案例

## 1. 项目概述

本案例在上一个弯曲分析案例（`examples/ibeam_fem`）的基础上，进一步对 I25a 工字梁进行**屈曲临界载荷分析**。上一案例反推得到材料屈服临界载荷约 124.77 kN，本案例将：

1. 用 FEM 计算从 **10 kN 到 120 kN**（步长 10 kN，共 12 个工况）的弯曲响应，观察从线弹性到临近屈服的全过程
2. 训练 PINNs 模型学习这一更大载荷范围下的非线性行为趋势
3. 反推并验证屈曲/屈服临界载荷

---

## 3. 边界条件

与弯曲案例相同：简支梁（左端 Pin + 右端 Roller），跨中施加集中力。

## 6. 技术路线

```
FEM 屈曲分析 (10~120 kN, 12工况)
       │
       ├─→ 线弹性 FEM: 挠度、应力随载荷的变化
       ├─→ 应力比分析: σ/σ_y 从 8% 增长到 96%
       └─→ 生成 NPZ 训练数据
       │
       ▼
PINNs 训练 (学习大变形范围的力学响应)
       │
       ├─→ 预测任意载荷下的挠度和应力
       └─→ 外推预测临界载荷附近的行为
       │
       ▼
对比验证 + 临界载荷分析
```
