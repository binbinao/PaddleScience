# 不用 ANSYS，不用 Abaqus，我用 AI 写代码做了一次有限元分析——然后 AI 自己学会了

## 先说结论

**AI 可以替代传统 CAE 仿真软件做工程计算，而且更快、更便宜、更灵活。**

为了证明这件事，我做了一个实验：让 AI 编程助手帮我写有限元代码，算出一根钢梁在不同压力下的弯曲变形；然后把计算结果喂给一个神经网络，让它"学会"钢梁的物理规律。学完之后，这个神经网络对任意压力都能直接给出答案，速度比有限元快了 **7 倍多**。

我必须坦诚：这个案例本身很小——一根 3 米的工字钢梁、一个跨中集中力、线弹性材料——翻开任何一本材料力学课本，用公式手算 30 秒就能得到精确答案。

**但这不是重点。**

重点是这个小案例背后跑通的那条完整链路：自然语言描述需求 → AI 自动查参数写代码 → 有限元数据生成 → 物理信息神经网络训练 → 实时预测替代传统仿真。这条链路放到任何复杂的三维结构、非线性材料、多物理场耦合问题上，逻辑完全一样，只是规模更大。

小例子，大趋势。AI for Engineering 的时代，已经来了。

## 我们在干什么？

先用大白话说清楚背景。

你在桥上走过，桥下面的钢梁会微微弯曲——肉眼看不见，但确实在弯。工程师需要算出"弯多少""会不会断"，这就是**结构力学分析**。

传统上，工程师用 ANSYS、Abaqus 这类 CAE（计算机辅助工程）软件来做这件事。这些软件功能强大，但也有几个绕不开的痛点：

- **贵**：一个商业 license 动辄几十万一年
- **重**：学习曲线陡峭，操作流程繁琐
- **慢**：复杂模型跑一次要几分钟甚至几小时
- **封闭**：算法是黑箱，想改点东西极其困难

那有没有另一条路？

有。这次我们的做法是：**AI 写代码做有限元 + AI 学会物理规律替代有限元**，全程不碰任何 CAE 软件。

## 第一步：让 AI 帮我写有限元代码

我们的分析对象是一根 3 米长的 I25a 工字钢梁——就是铁路和建筑里最常见的那种工字型钢材。两端简单支撑，中间施加一个向下的压力。

```
                    P (集中力)
                    ↓
    △              ↓               ○
    ║──────────────↓───────────────║
    A              C               B
   x=0          x=1.5m           x=3.0m
  (固定铰支座)   (加载点)        (滚动支座)
```

我需要算的是：压力从 1000 牛到 5000 牛（每 500 牛一个台阶，共 9 种压力），钢梁每个位置弯了多少。

在 AI IDE（CodeBuddy）里，我用自然语言描述了需求。AI 编程助手做了以下事情：

1. **自动上网查了 Q235 钢材的材料参数**（弹性模量 206GPa、密度 7850 kg/m³等），还从四个不同网站交叉验证，确保数据靠谱
2. **查了 I25a 工字钢的国标截面参数**（高 252mm、宽 118mm、惯性矩 5017 cm⁴ 等），同样多源交叉核实
3. **写出了完整的有限元分析代码**——100 个梁单元，组装刚度矩阵，施加边界条件，求解线性方程组
4. **一键运行**，9 个工况全部算完

AI 生成的有限元核心代码长这样——经典的 Euler-Bernoulli 梁单元刚度矩阵：

```python
def build_element_stiffness(E, I, le):
    """构建梁单元刚度矩阵 (4x4)"""
    coeff = E * I / (le ** 3)
    ke = coeff * np.array([
        [ 12,    6*le,  -12,    6*le ],
        [ 6*le,  4*le**2, -6*le, 2*le**2],
        [-12,   -6*le,   12,   -6*le ],
        [ 6*le,  2*le**2, -6*le, 4*le**2],
    ])
    return ke
```

## 第二步：让 AI 学会钢梁的物理规律

有限元算完了 9 种压力下的弯曲数据，一共 909 个数据点。接下来才是真正有意思的部分。

我们训练了一个叫 **PINNs（物理信息神经网络）**的小型 AI 模型。它和普通神经网络的区别在于：它不只是"记住"数据，还要"遵守"物理定律。

这个网络有多小？**总共只有 2,241 个参数**。对比一下，ChatGPT 有上千亿参数。我们这个模型小到可以跑在任何一台普通电脑上。

网络结构的核心代码，简洁到令人意外：

```python
class IBeamPINN(paddle.nn.Layer):
    def __init__(self, num_layers=3, hidden_size=32):
        super().__init__()
        layers = []
        in_dim = 2  # 输入：位置 x 和压力 P
        for _ in range(num_layers):
            layers.append(paddle.nn.Linear(in_dim, hidden_size))
            layers.append(paddle.nn.Tanh())
            in_dim = hidden_size
        layers.append(paddle.nn.Linear(in_dim, 1))  # 输出：弯曲量
        self.net = paddle.nn.Sequential(*layers)

    def forward(self, x_in):
        w_raw = self.net(x_in)
        x_norm = x_in[:, 0:1]
        P_norm = x_in[:, 1:2]
        # 物理先验硬编码：
        #   x*(1-x) 保证两端弯曲为零（边界条件）
        #   P_norm  利用"弯曲与压力成正比"的物理规律
        w = w_raw * x_norm * (1.0 - x_norm) * P_norm
        return w
```

注意最后那行 `w_raw * x_norm * (1.0 - x_norm) * P_norm`——这就是 PINNs 的精髓：**把物理知识直接嵌入网络结构**。网络不用费力去"学习"边界条件和线性叠加原理，因为我们已经在代码层面告诉它了。

我们往这个小网络里塞了三样东西：

- **数据**：FEM 算出来的 909 个弯曲值
- **物理定律**：梁的四阶微分方程（不需要懂这是什么，只需要知道这是牛顿力学的推论）
- **边界常识**：梁两端固定在支座上，弯曲量为零

然后在 GPU 上训练了大约 3 分钟。训练过程中，损失函数的下降曲线：

![训练损失曲线：黑色为总损失，蓝色为数据损失，红色为物理约束损失](outputs/pinn_results/training_loss.png)

数据损失快速收敛，物理约束（PDE 残差）从 1.0 下降了近 **6 个数量级**到 0.000003——意味着网络不仅拟合了数据，还高度遵守物理定律。

训练完成后，来看看 PINNs 在全部 9 个工况上的表现——蓝色是 FEM 真值，红色是 PINNs 预测：

![9 个工况全对比：PINNs（红色虚线）vs FEM（蓝色实线）](outputs/pinn_results/pinn_vs_fem_all.png)

曲线形态几乎完全吻合，误差稳定在 ~4.7%。

更酷的是，我们可以让 PINNs 对**整个参数空间**做预测——不只是 9 个离散的压力值，而是从 1000N 到 5000N 之间任意压力、任意位置的弯曲量。这张热力图展示了完整的预测场：

白色虚线是 9 条训练载荷。可以看到，线与线之间的预测是平滑连续的——**它不是在 9 个离散值之间做插值，而是真正学会了一个连续的物理场**。

训练完之后，我们给它试了 6 个**它从未见过的压力值**。结果：预测误差和训练数据上的误差一模一样，稳定在 4.7% 左右。

**它不是在背答案，它是真的学会了物理规律。**

## 见微知著：这件事为什么重要

这只是一个教科书级别的入门案例——一根直梁、一个集中力、线弹性材料。但它展示了一个完整的新范式：

### 旧范式
```
工程师 → 学习CAE软件(数月) → 建模(数小时) → 计算(数分钟~数小时) → 改参数重新算
```

### 新范式
```
工程师 + AI IDE → 自然语言描述需求(数分钟) → AI生成代码并运算 → 训练AI模型(数分钟) → 任意参数即时预测
```

这里面有三个关键的技术组合在同时发力：

**1. AI Coding（AI 编程）**

我不需要从零手写有限元代码。AI 编程助手理解我的工程意图后，自动查阅材料参数、编写求解器、生成可视化图表。它甚至会去网上交叉验证钢材属性数据——这在以前是工程师翻手册才能完成的事。

**2. GPU 算力**

PINNs 训练需要对神经网络做上万次迭代，每次迭代都要计算四阶微分——这在 CPU 上很慢，但 GPU 天生擅长大规模并行计算。15000 轮训练在 GPU 上只要 3 分钟。

**3. AI IDE（智能开发环境）**

从需求文档撰写、代码编写、调试运行、到结果分析，全部在一个智能 IDE 里闭环完成。不需要在多个工具之间切换，不需要手动管理文件和依赖。AI 就是你的结对编程伙伴。

**这三者的组合效应远大于各自之和。** 它们构成了一条完全绕开传统 CAE 工具链的技术路径。
