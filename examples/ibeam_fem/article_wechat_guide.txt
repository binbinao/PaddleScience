📄 文件：article_wechat.html

📌 发布方式（任选其一）：

━━━ 方式一：135编辑器 / 秀米（推荐）━━━

  1. 用浏览器打开 article_wechat.html
  2. Ctrl+A 全选 → Ctrl+C 复制
  3. 打开 135编辑器（www.135editor.com）或秀米（xiumi.us）
  4. 粘贴到编辑器中
  5. 逐张替换图片（搜索文中的 ▲ 标记找到图片位置）
  6. 导入微信公众号后台 → 预览 → 发布

━━━ 方式二：微信公众号后台直接粘贴 ━━━

  1. 用 Chrome 浏览器打开 article_wechat.html
  2. Ctrl+A 全选页面内容 → Ctrl+C 复制
  3. 登录 mp.weixin.qq.com → 图文消息 → 新建
  4. 在正文区域 Ctrl+V 粘贴
  5. 手动上传图片替换（共 9 张，见下方清单）
  6. 设置封面图 → 预览 → 发布

━━━ 方式三：直接粘贴 HTML 源码 ━━━

  1. 打开 article_wechat.html，复制全部 HTML 源码
  2. 在公众号后台编辑器中，切换到"HTML源代码"模式
  3. 粘贴源码
  4. 切回可视化模式，手动上传替换图片
  5. 预览 → 发布
