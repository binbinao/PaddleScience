## 二、FDFD方法：传统数值求解的天花板

FDFD（有限差分频域法）是计算电磁学的经典方法。我们的实现采用五点差分格式将Helmholtz方程离散化为稀疏线性系统：

```
(L + k²·diag(ε)) · E = J
```

其中 L 是 30552×30552 的五对角Laplacian矩阵，通过 `scipy.sparse.spsolve` 直接求解。

**实测性能：**

| 参数 | 值 |
|------|-----|
| 网格规模 | 201 × 152 = 30,552 节点 |
| 网格尺寸 | 0.02 cm（λ/10 @ 15GHz） |
| 单频求解时间 | **50 秒** |
| 频率扫描（13点） | **650 秒** |
| 最大场强 \|E\|\_max | 4.83 × 10⁴ |

FDFD的优势显而易见：**精确、稳定、理论成熟**。五十年的工程实践证明了它的可靠性。

但问题同样明显。50秒求解一个频率点，意味着：
- 一次13点频率扫描需要11分钟
- 参数优化（扫描100组几何参数 × 13个频率）需要**15小时**
- 实时控制场景（要求毫秒级响应）？**完全不可能**

这不是FDFD特有的瓶颈——FEM、MoM面临同样的问题。计算复杂度 O(N²) 到 O(N³)，网格节点数 N 受限于物理分辨率，没有捷径可走。

CAE行业花了几十年优化稀疏矩阵求解器、开发并行算法、设计自适应网格，但这些努力都是在同一个范式内的改良，没有改变"逐点求解"的本质。
