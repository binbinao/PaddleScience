## 三、PINN方法：从网格到神经网络的范式跳跃

PINN（Physics-Informed Neural Network，物理信息神经网络）的核心思想是：**用神经网络直接参数化物理场，用PDE残差作为损失函数训练网络**。不需要网格离散化，不需要组装大型线性系统。

我们的实现基于hPINNs（Hard-constraint PINN）架构，包含三个并行的MLP网络：

```
输入(x,y) → Fourier特征 → MLP_re → 电场实部 E_re
                        → MLP_im → 电场虚部 E_im  
                        → MLP_eps → 介电常数 ε
```

**关键技术细节：**

**1. Fourier特征嵌入。** 直接输入坐标(x,y)时，MLP难以学习高频振荡。我们将坐标映射为12个Fourier基函数（cos/sin），使网络能表达波动现象。

**2. 硬约束输出变换。** 通过 `(1-exp(a-y))·(1-exp(y-b))·network_output` 形式的变换，在网络结构层面强制满足PEC（完美电导体）边界条件 E=0，而非依赖软约束惩罚。

**3. 无量纲化。** 这是让PINN真正work的关键一步。物理频率 ω = 2π×15×10⁹ 的量级高达10¹⁰，直接代入Helmholtz残差会导致损失函数初始值达10²²，梯度爆炸，训练无法收敛。我们将频率归一化为 ω = 2π，坐标映射到[-2,3]的归一化域，使所有量级降到 O(1)。

这个教训值得强调：**相比原始hPINNs论文中ω=2π的光学问题，电磁工程的GHz频段高出10个数量级，不做无量纲化就不可能收敛**。

**4. 数据驱动训练。** 我们用FDFD的解作为监督标签，将10000个网格点的场值作为训练数据。网络同时学习输入坐标到输出场值的映射关系。

**训练过程：**

| 参数 | 值 |
|------|-----|
| 网络结构 | 4层 × 64隐藏单元 × 3网络 |
| 训练点数 | 10,000（FDFD子采样） |
| 训练轮数 | 5,000 epoch |
| 每epoch耗时 | 0.12 秒（Tesla T4 GPU） |
| 总训练时间 | **646 秒** |
| 最终Loss | 0.00000（MSE趋近于零） |

Loss从0.45指数下降到接近机器精度零，网络完整学会了FDFD的电磁场分布。
